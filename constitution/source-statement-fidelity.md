# Source-statement fidelity

Typed Web guarantees fidelity to observed origin representations and declared derivation.

A canonical result must identify:

- origin and URL;
- retrieval time;
- immutable body digest;
- observation digest;
- source locator;
- adapter identity and version;
- transformation chain;
- semantic mapping relation;
- exact semantic module closure.

The protocol does not assert that external provider content is objectively true.
