# ADR 014: Agent Utility Universes

Status: accepted architecture; corpus admission remains source-specific

Date: 2026-08-12

## Context

The Genesis Atlas controls origin identity, policy and retrieval. It is not by
itself a useful knowledge product. E4 needs coherent, queryable bodies of
public-source semantic state without making packet volume or catalog breadth a
substitute for utility.

## Decision

E4 organizes admitted frames into five independently measurable Agent Utility
Universes:

1. `tw:world-state` — public measurements and indicators;
2. `tw:opportunity` — grants, programs and explicit eligibility statements;
3. `tw:research` — scholarly metadata, updates and retractions;
4. `tw:security-standards` — vulnerabilities, regulations and standards;
5. `tw:agent-economy` — public machine capabilities and source-stated offers.

A universe is a versioned package that binds exact ontology modules, frame
types, source identities, mapping claims, materialized views, query templates,
visualizations, update policy and evaluation suite. It does not grant network
or execution authority. Source policy and the sealed work-order boundary remain
authoritative.

The public scoreboard reports independently:

```text
source records
semantic packets
semantic frames
distinct concepts
reviewed mappings
origins
materialized views
query coverage
real deltas
proof completeness
```

Controlled fixtures are always excluded from real-source totals. Archive
observations remain historical and cannot become current publisher statements.
Targets are stored separately from achieved metrics.

## First source order

The first importer foundations are World Bank Indicators and Grants.gov because
they provide a clear measurement universe and an immediately useful opportunity
universe. Implementation of an offline parser or conformance fixture does not
authorize retrieval. Every source requires a completed scope-specific policy
decision, exact routes, budgets, attribution and an emergency disable before a
network work order can exist.

## Query and agent boundary

Natural language may propose a canonical Semantic Query. Only the deterministic
executor may validate and run it against admitted immutable state. The visual
agent exposes concepts, the typed query, selected universe and indexes, proof
coverage and real execution timings. Narration is restricted to structured
results and proof references.

## Economic invariant

Funding, sponsorship, price and commercial value cannot affect semantic rank,
source authority, mapping trust, canon admission or governance. Money may fund
engineering, hosting, monitoring, support and private deployments around the
open protocol.

## Consequences

- TWIRX can demonstrate useful cross-origin investigations rather than a list
  of integrated sites.
- Each domain has explicit corpus, query, delta and proof acceptance evidence.
- The five universes can evolve independently while sharing the kernel.

## Rejected alternatives

- One undifferentiated million-packet corpus: rejected because it hides domain
  coverage and utility.
- One tool per origin: rejected because agents need a compact semantic query
  surface.
- Fetching all 500 candidates immediately: rejected because candidate
  selection is not retrieval authority and would bypass source-specific
  policy and capacity review.
