# E4 controlled capacity evidence

These reports describe invented `test_fixture` frames generated without
network access. They measure only the compact Universe Snapshot implementation
and contribute zero real origins, source records, observations or packets.

The 100,000-frame segment itself is intentionally not tracked. Its exact
digest and byte length are recorded in both reports; anyone can reproduce it
with `twirx-e4-capacity build` and verify/open it with
`twirx-e4-capacity open`.
