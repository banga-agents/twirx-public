verified source evidence. Generated counters distinguish real observations,
archive observations, replays, and controlled fixtures.

segment is a derived index over canonical packet, candidate mapping-claim and
frame objects retained in the release CAS. `release-manifest.json` is written
last and is the only publication admission marker. The proof index resolves
each frame to its packets, observation, representation, policy decision and
