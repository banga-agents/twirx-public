# Generated example artifacts

`demo-observation.json` and `demo-result.json` were produced by `make demo` from the controlled test origin.

The retrieval timestamp and observation/result digests will change on a new run. The body digest remains stable while the controlled representation remains byte-identical.

These files are explanatory examples, not normative conformance vectors.

`semantic-query-rfc-editor-history.json` queries the immutable read-only
snapshot for the exact source-native homepage title found in the two admitted
RFC Editor Common Crawl captures. It requires the `observed_native` lane and
does not request or imply a semantic mapping or current publisher statement.
