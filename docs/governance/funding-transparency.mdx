## Maintainer engineering capacity

Maintainer funding is reported as professional engineering capacity for a
defined period, project scope and set of published outputs.

## Wallet safety

Only public addresses enter the repository. Seed phrases, private keys, wallet backups, recovery data, and exchange credentials must never be committed.

A public chain is pseudonymous, not anonymous. Private GitHub sponsor visibility is not anonymity from the payment processor.

## Contribution rights

A contribution buys no equity, protocol ownership, technical vote, or guaranteed canon admission.
