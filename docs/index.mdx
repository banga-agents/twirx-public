# Give agents a trustworthy interface to the open Web

TWIRX is an open, language-neutral protocol for compiling public Web
representations into typed, reusable semantic state while preserving the exact
path from origin evidence to every returned value.

```text
public origin representation
    ↓
immutable observation
    ↓
source-native statement
    ↓
declared transformation
    ↓
semantic packet
    ↓
materialized read-only state
    ↓
typed query result with field-level provenance
```

The project does not certify that provider content is objectively true. It establishes a reproducible account of **what an origin represented and how the system derived the value it returned**.

## What exists today

The FUTO release candidate provides:

- 500 selected Atlas identities, not 500 working adapters;
- three completed human policy decisions;
- one real two-period Common Crawl archive profile;
- 15 public-source packets and five separately labeled fixture packets;
- one genuine source-native origin delta;
- two materialized views and one cross-origin query;
- an immutable read-only snapshot runtime with zero origin calls;
- independent bounded verification in the Genesis Go and C implementations;
- a fresh sanitized public repository with deterministic export manifest.

The controlled 25,018-packet result is capacity evidence from the real snapshot
path, but it is fixture-dominated. It is not 25,018 public facts and does not
mean 500 origins are compiled or live.

<Note>
The public Query Lab is live at `https://lab.twirx.org/` and serves one admitted
immutable snapshot with zero origin calls. TWIRX does not currently offer arbitrary URLs, browser or
model execution, authentication, payments, write actions, continuous crawling,
or production PostgreSQL.
</Note>
