## What TWIRX demonstrates

TWIRX observes a bounded origin representation, preserves source-native terms
and lexical values, compiles proof-bearing packets, materializes read-only
state, and answers typed queries without contacting an origin at query time.

## First real archive change

Two exact Common Crawl captures of the RFC Editor homepage produced two
source-native packets. The native `html:title` lexical value changed between
the selected 2025 and 2026 captures, so TWIRX emitted one `origin` delta.

It did not emit a semantic delta or canon delta because neither semantic
interpretation nor ontology changed. The archive evidence is historical,
observed by Common Crawl, and is not a current RFC Editor statement.

## Query proof

The snapshot resolves:

- a four-row cross-origin query spanning TWIRX and World Bank recorded state;
- a two-row RFC Editor archive-history query;
- zero origin-network requests for both queries;
- five controlled fixture packets excluded by default.

The runtime is immutable and read-only. It cannot refresh origins, accept a
URL, execute a browser or model, authenticate, purchase, or write semantic
state.

The public reviewer runtime is live at `https://lab.twirx.org/` and exposes the
bounded query, origin, trace, packet, delta and snapshot-manifest surfaces.

## Performance scope

A 5,000-request loopback stress run against the exact 20-packet snapshot had
5,000 successes, zero failures, zero origin calls, approximately 8,204 requests
per second and p95 latency of 1,123 microseconds. This is a small-snapshot,
single-host measurement, not a public or production capacity claim.

## Publication boundary

The public source profile publishes TWIRX-authored acquisition metadata,
digests, packets, deltas and reproduction commands. Exact third-party homepage
HTML and WARC bytes remain private pending a separate rights basis. This does
not alter the derived evidence.
