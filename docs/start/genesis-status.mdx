## Deliberately excluded

- arbitrary inference;
- HTML and browser extraction;
- model-assisted mapping;
- PostgreSQL and deployed public registry;
- Wasm adapter execution;
- public remote MCP and WebMCP serving;
- publisher verification;
- write actions and payments;
- blockchain anchoring;
- public multi-tenant deployment;
- fresh-origin execution through the public Query Lab.

The current generated Atlas metrics report 500 selected candidates, three
cataloged public identities, three completed human policy decisions, two
semantically linked technical records, one publisher-approved project origin,
and zero live origins. The decisions are `permit_live` for TWIRX,
`permit_with_constraints` for the bounded World Bank route, and `profile_only`
for two exact RFC Editor archive captures. Schedulers and budgets remain
disabled. The controlled origin is a test fixture and contributes to none of
the Genesis-500 public counters.

The FUTO snapshot contains 15 public-source packets, five excluded-by-default
fixture packets, one real origin delta, two views and 75 proof artifacts.

The protected FUTO snapshot remains the deployed baseline. A separate E4.5
Opportunity release candidate binds one founder-approved Grants.gov bulk
observation to 1,037,679 real source-derived packets, 747,783 candidate mappings
and 83,087 proof-linked frames. It is published as validated engineering
evidence but not deployed; its eligibility prose is withheld and no
current-openness or applicant-eligibility claim is inferred.

## Gate 1 evidence

The Gate 1 source-statement slice passes the local offline acceptance matrix as
of 2026-08-10. Parser bounds, atomic writes, adversarial vectors, Go and C
fuzzing, network-policy tests, corrupted-evidence rejection, and stopped-origin
offline replay are exercised together. Exact commands, totals, toolchains,
benchmarks, and residual risks are recorded in `reports/gate-1-genesis.md`.

Gate 1 is still pre-alpha evidence, not authorization for public multi-tenant
deployment. CI review and independent security review remain separate gates.
