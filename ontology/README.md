# E4 ontology authoring tree

This directory contains bounded Genesis authoring records for the E4 Ontology
Fabric. The exact JSON bytes are hashed into canonical module manifests. JSON
is an authoring carriage; the language-neutral specification and deterministic
CBOR objects remain authoritative.

Current modules and universes are **draft implementation candidates**. Their
presence does not admit a semantic mapping, source retrieval, corpus claim or
public deployment. Released modules require a separately digest-bound human
review decision.

Normal tests compile this tree without network access.
