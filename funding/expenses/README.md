# Project expense records

Create one Markdown file per material expense:

```text
YYYY-MM-DD_vendor_category.md
```

Include:

- ledger entry ID;
- vendor and service;
- date;
- amount and asset;
- USD reference value;
- purpose;
- which project component uses it;
- renewal or termination date;
- public receipt path or retained-original hash;
- any allocation shared with another project.

Do not publish secrets, account identifiers that enable takeover, personal addresses, full payment details, or unredacted tax information.
