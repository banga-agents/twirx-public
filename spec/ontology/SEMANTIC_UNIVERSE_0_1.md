# Semantic Universe 0.1

**Authority:** Normative for E4.0 universe conformance

**Status:** Implementation candidate under founder review

A semantic universe is a versioned domain package. It binds exact modules,
frame types, source identities, mapping claims, materialized views, query
templates, visualizations, update policy, evaluation suite and compiled module
set. It grants no retrieval or execution authority.

The initial universe identifiers are:

```text
tw:world-state
tw:opportunity
tw:research
tw:security-standards
tw:agent-economy
```

The canonical universe core is self-digest-free:

```text
universe_digest = SHA-256(exact canonical semantic-universe-core bytes)
```

Actual counters are generated from admitted artifacts and remain separate from
targets. The minimum public accounting separates source records, packets,
frames, concepts, reviewed mappings, origins, views, query coverage, deltas and
proof completeness. Fixtures never count as real source evidence.

The universe package cannot broaden an origin policy decision, sealed route,
rate budget, effect class or source retention rule. A materialized view remains
a rebuildable proof-linked projection.
